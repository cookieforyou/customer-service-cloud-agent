## 1. 机制说明

- **编号**：`坑#NN` 纯文本，连续递增、只增不改（不使用带圈数字——50 号封顶且跳号要永久解释，姊妹项目实证教训）。
- **模板**：`**病名（症状+根因一句话）**——机制解释——治法（具体代码/配置）——（触发阶段/轮次、联动章节版本号）`。
- **四点联动**（登记一个坑必须同步四处）：
  1. 本台账续编（新行）；
  2. 对应设计章修订注记（`vN.M(坑#xx 续编:…)`，章头版本链同步）；
  3. AGENTS.md「坑位钩子」仅加一句话版（全量台账在本文件，AGENTS.md 控体积）；
  4. 提交信息带坑号（`fix(域): …（坑#xx）`）+ 对应 M 卷任务行/热修行补记。
- 姊妹项目全量台账（①-㊿，50 条）见其仓库 `docs/project-implement/19-附录.md` 附录 E——本文件仅收录与本平台技术面相关的条目作**预置继承**。

## 3. 本平台实证坑位（首坑即启）

| # | 坑位 |
|---|---|
| 坑#13 | **Testcontainers 2.x 三处 API 形态变化，按 1.x 记忆写码必错**——artifact 改名（`testcontainers-postgresql`/`testcontainers-junit-jupiter`，旧 `postgresql`/`junit-jupiter` 在 BOM 中无版本致 Maven 解析失败）；`PostgreSQLContainer` 迁包 `org.testcontainers.postgresql`；类已非泛型（`<?>` 编译错）——依姊妹项目 2.0.5 同栈写法核验后落码（M0批2，V1 样板即 ConversationPersistenceIntegrationTest） |
| 坑#14 | **嵌套 JdbcTemplate 不保证与外层 ConnectionCallback 同连接——SET ROLE/SET LOCAL 场景 GUC 与数据语句分家**——JPA 事务管理器对 JDBC 连接暴露时机的坑：外层回调里 `SET LOCAL cs.tenant_id` 生效的连接 ≠ 内层 `jdbc.update` 借到的连接，RLS fail-closed 直接拒绝（表象是「本租户写入也被拒」）——会话级 GUC/角色场景必须**同一条 Connection 内完成全部语句**（PreparedStatement 手工执行），finally 中 RESET ROLE 在 abort 事务上必 25P02 需吞掉保原始异常（M0批2） |
| 坑#15 | **Boot 4 = Jackson 3（`tools.jackson`），starter-web 不再携带 `com.fasterxml.jackson`**——按 2.x 习惯 import `com.fasterxml.jackson.databind.ObjectMapper` 直接编译失败；手工构造用 `JsonMapper`，且 `readTree` 等方法签名微调（M0批3） |
| 坑#16 | **Framework 7 WebTestClient API 变形**——`retrieve()` 改名 `exchange()`、`exchangeToMono` 不存在、包路径仍为 `org.springframework.test.web.reactive.server`；SSE 流测试改用普通 `WebClient` + `spring-boot-starter-webflux`(test) 更稳（姊妹同款组合）（M0批3） |
| 坑#17 | **`Sinks.many().multicast().onBackpressureBuffer()` 自带历史回放**——与手工补发缓冲 concat 后每帧双发（测试见 12 帧应为 6）；补发场景应 `directBestEffort`（热流不存历史，缓冲为补发唯一来源）（M0批3） |
| 坑#18 | **PG 唯一键冲突后事务即毒化（25P02），catch 后同事务内的任何补偿 SQL 必失败**——幂等兜底正确结构：冲突异常滚出事务边界，补偿读走**新事务**（ChatService 捕获 DataIntegrityViolation 后经 ConversationPort.inboundMessageId 独立事务读取）（M0批3） |
| 坑#19 | **Casdoor JWT 实测契约与假设不符三处**——① `roles` 为**对象数组**，角色名在元素内 `name` 字段（**顶层 `name` 是用户名**，两处同名字段极易混用）；② JWKS 端点 = `/.well-known/jwks`（**无 `.json` 后缀**，带后缀路由返回空 `{"keys":[]}`；以 OIDC discovery 为权威）；③ `/api/jwt/public-key`、`/api/jwks` 需管理鉴权不可匿名用——外部身份契约必须以真实 token + discovery 实测定型再落码（INF-2 回传 2026-09-20 实证：RS256 验签 openssl 独立通过、`owner`=组织即租户、`aud`=`{client_id}-org-{org}`、TTL 7 天）；治法 = SecurityConfig.roleName 按 `roles[].name` 提取并兼容字符串形态 + AuthorityConverterTest 镜像真实 payload 钉死；另附 Framework 7 / Security 7 实测：bearer 认证默认追加 `FACTOR_BEARER` authority，测试精确断言须过滤角色面（INF-2 销账批 2026-09-20，《11》§7 v1.3.0） |

## 4. AGENTS.md 坑位钩子（一句话版，高频项）

- 坑#01：MCP server 暴露必须显式 `protocol: STREAMABLE`。
- 坑#02：a2a-java SDK 有 Spring 适配判负先例，A2A server 优先自研预案。
- 坑#04：多 ChatClient/ExecutorService Bean 消费点必须显式 `@Qualifier`。
- 坑#05/坑#11：关键配置必须契约测试钉结构与缺省值。
- 坑#13：Testcontainers 2.x artifact 已改名（testcontainers-postgresql / testcontainers-junit-jupiter）、PostgreSQLContainer 迁包 `org.testcontainers.postgresql` 且非泛型。
- 坑#15：Boot 4 = Jackson 3（`tools.jackson.*`），`com.fasterxml.jackson.databind` 不在 starter-web 类路径。
- 坑#19：Casdoor `roles` 为对象数组、角色名取元素内 `name`（顶层 `name`=用户名勿混用）；JWKS 端点以 OIDC discovery 为准（`/.well-known/jwks`，无 `.json` 后缀）。
